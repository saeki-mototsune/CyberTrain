01Открыть codespace

ЗачемVS Code в вашем браузере, на облачной машине, работающей за счёт вашей собственной квоты GitHub.

Открыть в GitHub Codespaces→ Читать учебник

Нужен аккаунт GitHub, а codespace работает за счёт вашей собственной квоты Codespaces: бесплатный план GitHub включает 120 ядро-часов и 15 ГБ-месяцев хранилища в месяц — это около 60 часов на стандартной 2-ядерной машине, которую использует песочница. По умолчанию GitHub останавливает простаивающий codespace через 30 минут; его хранилище учитывается, пока вы его не удалите.

02Что откроется

  • Блог с выполненными шагами учебника 02, 03, 04 и 07: cybertrain new blog, скаффолд статей, корневой маршрут и первая миграция; он уже собран один раз, поэтому сервер запускается без компиляции.
  • Терминал, в котором запущен cybertrain server.
  • Приложение в новой вкладке браузера со списком статей.
  • PLAYGROUND.md — краткое руководство о том, что попробовать.
  • Source Control: приложение — это git-репозиторий с одним коммитом, поэтому там видно ровно то, что вы меняете.

Если VS Code спросит, доверяете ли вы авторам файлов в этой папке, выберите «Trust Folder & Continue»: только после этого запустится терминал сервера.

03Что попробовать

  • Измените представление. Изменение появится при следующей перезагрузке страницы: представления читаются с диска при каждом запросе.
  • Добавьте валидацию. Ruby компилируется, поэтому изменение в Ruby означает полную пересборку — около минуты, после чего сервер перезапускается сам.
  • Продолжите учебник с шага 08, «Скаффолд комментариев».
  • Создайте новое приложение. cybertrain new работает в codespace без сети.

Вкладка приложения сама не перезагружается: перезагрузите её после изменения. Если вкладка приложения не открылась (блокировщик всплывающих окон или codespace был остановлен и перезапущен), воспользуйтесь командой «Open in Browser» для порта 3000 в панели Ports.

04Запуск в Docker

ЗачемТот же образ запускается и на вашей собственной машине.

Затем откройте http://localhost:3000. Опубликованный образ — linux/amd64; на машине arm64 соберите его из локальной копии репозитория, как описано в playground/README.md.
